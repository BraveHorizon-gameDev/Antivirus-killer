# ANTIVIRUS KILLER

ANTIVIRUS KILLER is a hardcore infinite survival FPS developed in Unity.

The player controls an antivirus shield fighting against endless waves of aggressive viruses inside a computer. The difficulty increases continuously, turning the game into a test of focus, reaction speed, and survival skill.

One mistake can end everything.

---

## Features

- Infinite wave survival system
- Increasing difficulty and chaos
- Instant-kill precision shooting
- Randomized enemy spawning
- Minimal UI (Health + Wave)
- Pause and Game Over system
- Fast-paced FPS gameplay

---

## Controls

| Key | Action |
